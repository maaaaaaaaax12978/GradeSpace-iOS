# GradeSpace: установка через Safari без IPA

Приложение включает предметы, оценки с весами, призрачные оценки, четыре четверти, завершение четверти и годовую оценку, светлую и тёмную тему.

## 1. Один раз включить GitHub Pages

Открой https://github.com/maaaaaaaaax12978/GradeSpace-iOS/settings/pages под владельцем репозитория.
В Build and deployment выбери:
- Source: Deploy from a branch
- Branch: main
- Folder: /docs
Нажми Save. Дождись сообщения о публикации и ссылки Visit site. Обычно это занимает несколько минут.
Если сайт не появился, открой вкладку Actions и проверь задачу pages build and deployment.

Адрес после публикации: https://maaaaaaaaax12978.github.io/GradeSpace-iOS/
До включения Pages этот адрес может показывать 404.

## 2. Установить на iPhone

1. Открой опубликованный адрес именно в Safari.
2. Нажми «Поделиться». В некоторых версиях Safari эта кнопка находится в меню страницы.
3. Выбери «На экран Домой».
4. Если есть переключатель «Открыть как веб-приложение», включи его.
5. Нажми «Добавить».
6. Открой новую иконку с интернетом один раз. Вноси оценки уже в окне установленного приложения. В настройках приложения дождись сообщения о готовности офлайн-версии.

Никакие Apple ID, Scarlet, Sideloadly, сертификаты или режим разработчика для этого способа не нужны. Подпись не требуется, поэтому еженедельного переподписывания нет. Это веб-приложение с отдельным окном и иконкой.

## 3. Сохранение и резервная копия

Оценки сохраняются локально в установленном веб-приложении. Они не отправляются в репозиторий GitHub и не синхронизируются между устройствами.
В «Настройки → Сохранить резервную копию» регулярно сохраняй JSON-файл. Это особенно важно перед удалением приложения, очисткой данных Safari или сменой телефона. Восстановление — «Загрузить журнал».
Данные Safari и установленного веб-приложения могут быть раздельными: начинай работу из новой иконки. Для переноса уже введённых данных используй экспорт и импорт.

После успешного кэширования дневник может работать без интернета. Первый запуск, установка обновлений и восстановление удалённого браузером кэша требуют сети.

## 4. Windows

В Edge или Chrome открой тот же опубликованный адрес. В меню браузера выбери установку сайта как приложения, если такой пункт доступен. Журнал на Windows будет отдельным; перенос — через JSON.

## 5. Четверти и год

Выбирай четверть и вводи настоящие оценки с весами. «Завершить четверть» предлагает округлённый средний настоящих оценок, без призрачных. Итог можно исправить на оценку, выставленную учителем.
После завершения всех четырёх четвертей появится официальная годовая. Незавершённые четверти участвуют только в предварительном прогнозе.
