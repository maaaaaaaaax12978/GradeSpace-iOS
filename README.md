# GradeSpace — приложение iPhone со сборкой из Windows

Это проект iOS-приложения. Архив проекта нельзя сразу установить в Scarlet. Сначала GitHub Actions собирает `GradeSpace-unsigned.ipa` на облачном Mac, затем Scarlet подписывает и устанавливает этот IPA на iPhone. Свой Mac для этого способа не нужен.

Интерфейс со стеклянными карточками, светлой и тёмной темами встроен в приложение. Для работы дневника не нужен сайт или хостинг. Требуется **iOS 16 или новее**.

**Статус:** подготовлены исходники, иконки, проверка JavaScript и автоматическая сборка. Расчёты, проверка данных и интерфейс обмена с iOS-оболочкой проверены на Windows. Настоящая компиляция Xcode, подпись и запуск на физическом iPhone ещё не выполнены. Успешное получение IPA подтвердит только зелёный результат сборки GitHub Actions.

## 1. Что потребуется

- Компьютер с Windows и браузером.
- iPhone с iOS 16 или новее: версию можно посмотреть в **Настройки → Основные → Об этом устройстве**.
- Аккаунт GitHub для облачной сборки и скачивания её результата.
- Работающий Scarlet с действующей подписью либо другой инструмент подписи и установки собственного IPA.
- Интернет для сборки и установки. После установки дневник работает локально.

Apple Developer за $99 в год для сборки **неподписанного** IPA этим сценарием не требуется. Для установки всё равно нужна действующая подпись, которую предоставляет выбранный способ установки. Создание unsigned IPA само по себе не даёт устройству разрешения его запустить.

Не загружай в репозиторий свои `journal.xml`, резервные копии, сертификаты или пароли: для этой сборки нужны только файлы проекта. Сам архив проекта личных оценок не содержит.

## 2. Распакуй проект на Windows

1. Скачай **GradeSpace-iOS-project.zip** из чата.
2. Нажми на архив правой кнопкой → **Извлечь всё**.
3. Открой распакованную папку. Внутри должны находиться:

   ```text
   .github/
     workflows/
       build-ios.yml
   GradeSpace/
     AppDelegate.swift
     Assets.xcassets/
     Web/
   scripts/
     check.cjs
   project.yml
   README.md
   .gitignore
   ```

Не используй для этих шагов старые архивы Windows-приложения или веб-приложения. В них нет iOS-сборки.

## 3. Загрузи проект на GitHub

1. На компьютере открой [github.com](https://github.com/) и войди в свой аккаунт. Если аккаунта нет, зарегистрируйся самостоятельно.
2. Нажми **+ → New repository**. Назови репозиторий `GradeSpace-iOS`.
3. Выбери видимость. **Public** делает исходники общедоступными; стандартные GitHub Actions для публичных репозиториев предоставляются бесплатно. **Private** оставляет исходники закрытыми и использует лимит Actions твоего тарифа. См. [условия GitHub Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions).
4. Нажми **Create repository**.
5. На странице нового репозитория выбери **uploading an existing file**. Если репозиторий уже содержит файлы: **Add file → Upload files**.
6. Открой распакованную папку на компьютере. Выдели её содержимое: `.github`, `GradeSpace`, `scripts`, `project.yml`, `README.md` и `.gitignore`. Перетащи на страницу загрузки. Нужны сами файлы и папки внутри проекта, а не ZIP и не ещё одна внешняя папка `GradeSpace-iOS`.
7. Дождись загрузки и нажми **Commit changes**.
8. На главной странице репозитория `project.yml` должен находиться сразу в корне, рядом с папками `GradeSpace` и `scripts`.

### Если папка .github не загрузилась

Проверь путь `.github/workflows/build-ios.yml` в репозитории. Если его нет:

1. Нажми **Add file → Create new file**.
2. В поле имени введи **`.github/workflows/build-ios.yml`** целиком. GitHub создаст нужные папки.
3. На компьютере открой файл `.github/workflows/build-ios.yml` из архива в Блокноте. Можно использовать отдельный файл **Build-iPhone-IPA.yml**, приложенный в чате: его содержимое такое же.
4. Скопируй весь текст файла и вставь в редактор GitHub.
5. Нажми **Commit changes** и сохрани в основную ветку репозитория.

## 4. Запусти сборку IPA

1. В репозитории открой вкладку **Actions**.
2. Если GitHub предложит разрешить Actions в этом репозитории, включи их.
3. Слева выбери **Build iPhone IPA**.
4. Нажми **Run workflow**, оставь основную ветку и ещё раз нажми **Run workflow**.
5. Открой появившийся запуск и дождись завершения. Время зависит от очереди GitHub и установки инструментов.
6. Зелёная галочка означает, что компиляция и упаковка завершились. Красный крест означает ошибку; файл IPA в таком случае нельзя считать готовым.

В этом сценарии GitHub запускает стандартный `macos-15`, генерирует Xcode-проект и собирает приложение для настоящего iPhone без подписи. Сертификаты, Apple ID и секреты в настройки репозитория добавлять не требуется. Сборка запускается вручную, а не при каждом изменении файлов.

Официальная справка: [ручной запуск workflow](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow).

## 5. Скачай именно IPA

1. На странице успешно завершённой сборки прокрути вниз до раздела **Artifacts**.
2. Нажми **GradeSpace-IPA**. Для скачивания нужно быть авторизованным в GitHub.
3. Скачается ZIP-архив результата. **Распакуй этот внешний ZIP один раз**.
4. Внутри находится **`GradeSpace-unsigned.ipa`**. Это и есть приложение для подписи. Сам IPA дополнительно распаковывать или переименовывать не нужно.
5. Передай IPA на iPhone и сохрани в приложении **«Файлы»**. Можно скачать артефакт в Safari на iPhone под тем же аккаунтом GitHub, открыть загрузки и распаковать ZIP в «Файлах».

Артефакт этой сборки хранится 7 дней. Если срок истёк, запусти сборку ещё раз.

Официальная справка: [скачивание артефактов](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts).

## 6. Установи через Scarlet

### Если Scarlet уже открывается

1. Убедись, что `GradeSpace-unsigned.ipa` находится в «Файлах» на iPhone, а не остался внутри внешнего ZIP-архива.
2. Открой Scarlet.
3. Открой раздел установленных приложений/загрузок. Нажми кнопку импорта IPA: обычно это значок загрузки или **+**. Расположение зависит от версии Scarlet.
4. Выбери **`GradeSpace-unsigned.ipa`** через окно «Файлы».
5. Дождись подписи и обработки. Когда iOS предложит установить **GradeSpace**, нажми **«Установить»**.
6. Открой GradeSpace с главного экрана.
7. Создай предмет, добавь одну настоящую оценку, закрой приложение и открой снова. Так ты проверишь сохранение на своём iPhone.

В отличие от веб-версии, здесь не нужно нажимать «На экран Домой»: иконка появляется после установки IPA.

### Если Scarlet ещё не установлен

Начни с сайта проекта [usescarlet.com](https://usescarlet.com/) и его [документации](https://docs.usescarlet.com/). Доступность прямой установки меняется: **Signed** означает, что она доступна, **Revoked** — что используемая подпись отозвана. Я не проверял текущую доступность сертификата на твоём устройстве.

При доступной прямой установке обычно выполняются такие шаги:

1. Открыть сайт Scarlet в Safari и перейти к **Install → Direct Install**.
2. Подтвердить установку Scarlet.
3. Если iOS сообщает «Ненадёжный корпоративный разработчик», открыть **Настройки → Основные → VPN и управление устройством** и подтвердить доверие соответствующему разработчику установленного Scarlet.
4. Открыть Scarlet и выполнить импорт IPA из предыдущего раздела.

При статусе **Revoked** эти действия не восстановят сертификат. Нужна действующая подпись или другой поддерживаемый способ установки. Не требуется jailbreak и не нужно менять дату телефона или отключать проверку сертификатов.

## 7. Если Scarlet не подходит: вариант с Windows

Тот же IPA можно подписать и установить через **[Sideloadly](https://sideloadly.io/)** на Windows. Понадобятся iPhone, USB-кабель и твой Apple Account. Устанавливай программу и компоненты Apple по инструкции с сайта Sideloadly.

Общая последовательность: подключить iPhone → подтвердить доверие компьютеру → выбрать устройство в Sideloadly → указать IPA и свой Apple Account → запустить подпись и установку. Если iOS попросит довериться разработчику или включить режим разработчика, выполни соответствующие шаги на самом телефоне. Бесплатная подпись требует периодического обновления; конкретные ограничения зависят от способа и аккаунта. Подробности и решение ошибок: [официальный FAQ Sideloadly](https://sideloadly.io/faq).

## 8. Перенос оценок и резервная копия

- В GradeSpace открой **Настройки → Сохранить резервную копию**. Появится системное меню «Поделиться»: выбери **«Сохранить в Файлы»**.
- Для восстановления выбери **Настройки → Загрузить журнал**. Поддерживаются JSON-копия GradeSpace и `journal.xml` из Windows-версии. После выбора файла приложение запросит подтверждение замены текущего журнала.
- Windows-журнал находится в `%LOCALAPPDATA%\GradeSpace\journal.xml`. Открой этот путь через **Win + R**, перенеси файл на iPhone и импортируй его.
- Сохранение из Safari не переносится в установленное приложение автоматически: сначала экспортируй JSON из веб-версии, затем импортируй его в iOS-приложении.
- Перед удалением приложения, изменением идентификатора при подписи или переустановкой сохрани копию в «Файлы». Срок жизни подписи не равен сроку хранения резервной копии.

## 9. Частые проблемы

**Не вижу Build iPhone IPA во вкладке Actions.** Проверь, что файл находится по пути `.github/workflows/build-ios.yml` в основной ветке, а не внутри дополнительной папки. При необходимости создай его вручную по разделу 3.

**Нет кнопки Run workflow.** Открой именно workflow слева. Убедись, что файл сохранён в основной ветке и в нём есть `workflow_dispatch`.

**Сборка красная.** Открой запуск → `build` → красный шаг. Скопируй текст первой ошибки или скачай `GradeSpace-build-log` из Artifacts, если он появился. Отправь текст ошибки в этот чат. Исходники пока не прошли реальную компиляцию Xcode в этой среде, поэтому первая облачная сборка является обязательной проверкой.

**Artifacts пустой.** Обычно сборка не завершилась успешно, ты открыл не страницу запуска или не вошёл в GitHub. После успешной сборки нужен артефакт **GradeSpace-IPA**, а не архив исходников репозитория.

**Scarlet не видит файл.** Выбери `GradeSpace-unsigned.ipa` из распакованного артефакта. `GradeSpace-iOS-project.zip` — это исходники, а не приложение.

**«Невозможно проверить приложение» / «Не удаётся установить».** Проверь состояние подписи Scarlet, совместимость iOS и правильность IPA. Если подпись отозвана, новая сборка того же кода это не исправит. Вариант с Windows описан в разделе 7.

**Приложение запускается и закрывается.** Если подпись действующая, сохрани модель iPhone, версию iOS и текст ошибки. При наличии доступа к аналитике iPhone можно приложить соответствующий отчёт о сбое. Приложение нужно проверить на реальном устройстве: одних проверок исходников недостаточно.

**Хочу TestFlight.** Этот workflow выпускает неподписанный IPA для последующей подписи, не TestFlight-сборку. Для TestFlight нужен отдельный процесс подписи и загрузки в App Store Connect с членством Apple Developer Program. Для внешних тестировщиков применяется бета-проверка Apple; сборка доступна до 90 дней. См. [TestFlight](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/).

## Технические детали проекта

Оболочка UIKit/WKWebView загружает файлы интерфейса из пакета приложения. Журнал записывается атомарно в `Application Support/GradeSpace/journal.json`, предыдущее состояние — в `journal.previous.json`. Сохранение не зависит от localStorage Safari. Импорт открывает системный выбор документов, экспорт — системное меню «Поделиться». Переходы веб-представления ограничены встроенной папкой; внешние HTTP/HTTPS-ссылки открываются отдельно.

Генератор проекта: [XcodeGen](https://github.com/yonaskolb/XcodeGen). Он устанавливается только на облачном Mac во время сборки, на Windows устанавливать его не нужно.
